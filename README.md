A single deadpan one-liner in the GPS's own voice: its excuse for sending the driver down the wrong road — the dead end was a shortcut in beta, and the road just hadn't finished loading yet.

## Run it

```sh
python3 main.py
```

It writes one line of comedy (105 characters) to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
